# 평단·손익 계산기 v1.1

분할매수·매도·수익률을 **수수료·세금까지 반영**해 계산하는 모바일 웹앱.
링크: https://heminism00-blip.github.io/pyeongdan-calc/

---

## v1.1 요약
아이콘에 **"평단" 글자**를 넣어 홈 화면에서 바로 식별되게 했습니다. (v1.0: 이름·아이콘·매니페스트 + 버전 이력 관리 시작)

## 주요 기능
- **매수** — 보유분 + **분할 추가매수(여러 번)** → 최종 평균단가 자동 합산
- **매도** — 수수료·세금 반영 **순 실현손익** + **🎯 손익분기 매도가**
- **목표 역산** — 목표 수익률(%)/손익(원) 입력 → 필요 매도가 자동 설정
- **호가 단위 자동** (100/500/1,000원) · 천단위 콤마 · 다크모드
- **색 구분** — 매수=핑크 / 추가매수=옐로우 / 매도=블루
- **수수료 계산** — 율(%) 예측 / 금액 직접(체결내역 정확 반영) 토글
- **일부 매도** 시 남은 보유분 평가손익 별도 표시

## 사용
- PC: 링크 열고 **북마크**
- 모바일: 링크 열고 **"홈 화면에 추가"** → "평단계산기" 아이콘으로 실행
